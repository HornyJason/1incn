# 十四亿分之一：中国模式 0.4 交互更新

[在线游玩](https://hornyjason.github.io/1incn/) · [源码仓库](https://github.com/HornyJason/1incn)

0.4 已恢复原项目的书信、聊天、来电、邮件、填涂表格和签字盖章组件，并将主界面改回原版属性条、时间线和舞台布局。完整更新与验证说明见 [README.md](README.md#04恢复原作-ui-与叙事细节)。以下保留原有模型说明；存档结构仍兼容 0.3。

在 [satorunet/1injp](https://github.com/satorunet/1injp) 源码基础上扩展的现代中国人生模拟器。沿用原作的配色、像素人物、插图和种子随机数，静态运行，无构建步骤、登录或运行时 AI 接口。

```sh
python3 -m http.server 4179 --bind 127.0.0.1
```

浏览器打开 http://127.0.0.1:4179 。Node.js 只用于模型验证。

## 0.3 更新

- 恢复原作 `.pxstage` 舞台与 `.famscene` 家庭动画，直接迁移 `app.js` 中的像素道具、呼吸、跳跃、走路、家人同行、事件动作和出生家庭场景。适配中文字段，不加载原作的日本游戏引擎界面。
- 学龄前隐藏生活重心，六岁后显示；引擎也不对学龄前应用生活重心加成。生活重心、事件筛选使用自定义菜单，支持键盘、触控与焦点反馈。
- 资产管理支持最多 5 套房的全款/首付购买、自住、出租、空置、出售；每年更新估值、租金、维护及还贷。车辆支持买卖、用车费用与折旧。旧房产迁为名下房产，旧借款余额保留。
- 酷儿相关支线按**整局 3%**开关抽样，不逐年累加。其中约 2/3 是主角同性心动，约 1/3 是直人收到同性告白；不是现实人口统计。同性伴侣进入长期承诺而非异性婚育分支。
- 出柜分朋友、家人、工作场合独立选择。自动模式也必须等待玩家决定；向家人朋友公开不会自动传至职场。工作场合公开后，虚构基层单位有晋升歧视情节，可寻求支持、保留岗位或离职转企业。它不是现实政策说明。

## 中国生活

- 内地 31 省区市、城乡和家庭底色、中文家庭姓名与人民币收支。
- 小学、初中、中考、大学与高职、专业选择、考研、初次就业、公考尝试、企业与灵活就业。
- 婚恋、孩子成长、春节团聚、回乡与迁居、父母照护、退休和晚年安排。
- 各地早餐、地方记忆和日常情节；父母使用与其出生年代更相符的姓名样本，去世后显示享年。
- 城市分档的住房、租金、日常成本；账本分列个人到账、伴侣共同投入、学费、教育借款、育儿、照护、住房本金与利息。
- 每年可主动安排一次运动、阅读、家人相处、短假、技能课或休息。

## 存档兼容

继续使用 `1incn-v1:` 浏览器存储键，接受 `cn-0.1.0`、`cn-0.2.0` 与 `cn-0.3.0` 的有效 JSON。旧版姓名、年龄、便签、时间线与已做选择保留，新增字段按迁移规则补充；此后推进采用新版本规则，因此升级前后的未来结果不保证相同。

导入文件上限 2 MB。解析和结构检查通过后才替换当前记录，异常文件不覆盖原存档。导入与模拟不上传数据。清除浏览器数据会删除本地记录，重要人生请导出保存。

## 文件关系

- `index.html`、`cn-app.js`、`cn.css`：入口、交互与中国模式布局。
- `cn-engine.js`：生命周期、选择、种子恢复与存档检查。
- `cn-local.js`：中国生活分支、地域素材、住房与收支、年度主动安排。
- `cn-views.js`：账本、同日人生、点滴收集与离线人生册。
- `cn-data.js`：省级人口、全国指标、姓名与模型参数、数据来源。
- `cn-assets.js`：资产交易、贷款归集、房价和租金、车辆费用与折旧。
- `cn-queer.js`：整局低频支线、取向、告白、分范围出柜及虚构职场偏见。
- `cn-animation.js`：从原作直接迁移的舞台与出生家庭动画。
- `cn-visuals.js`：从原作 `app.js` 提取的像素人物，调整了校服配色。
- `data.js`、`engine.js`、`style.css`、`illust.js`、`pxscenes.js`、`audio.js`、`clair.js` 等为保留的上游实现与资源。
- `upstream/` 保存原作首页和 README 快照；其余原作源码供后续迁移参考。公共仓库快照获取日期为 2026-10-23。

## 数据和模型范围

省份以 2020 年七普常住人口加权，**不是当前各省年度出生比例**；代表城市随机选取。全国人口、出生、死亡与人均可支配收入采用 2025 年统计公报。完整出处在 `cn-data.js` 和界面的数据说明中。

城乡、家庭、姓名、录取、职业收入、城市价格档位、婚恋、照护和退休是游戏设定。借款固定参数仅用于模拟，不对应真实报价或政策；寿命仍使用简化模型，尚未按中国生命表校准。地方食物和生活场景是叙事素材，不代表当地每个人的生活。

只含当代模式，未迁移日本时代模式、真实机构名单和联网排行榜。人生簿是本地记录，“同日人生”不是统计研究。
