## 0.7：家庭安排与更平稳的阅读

- 时间线只插入新记录，保留已有节点；彻底禁用事件入场、淡入淡出和过渡，年内逐条出现的节奏不变。
- 知识恢复适中的在校自然积累，学习重心提高积累速度；选择奖励按整数给出，正向至少 +1。兴趣课 +1、技能课 +2，继续教育每年积累并按期结业。
- 自动分配重点、普通或私立高中；私立需宽裕家境。高中类型只影响第一志愿录取判定，最多增加 5 个百分点，不直接加高考分。查分后可以不填志愿、直接就业，高中毕业前日常由家人承担。
- 招聘保留三个不同岗位，选中即办理入职；移除刷新与第二次面试。邮件正文和选项在同一区域滚动。
- 生活安排直接在同一按钮上再次点击确认；关闭栏固定在弹窗顶部。现金足够覆盖全部剩余借款时，自动结清教育和住房借款，更新账本与净资产。
- 新增次年审核的领养、按城市预算选择的红包；孩子升学、兄弟姐妹结婚和朋友婚礼会询问红包安排，朋友婚礼一生最多提示一次。退休后有孙辈时，仅抽取一次 50% 概率询问照护，同意后带伴侣搬去孩子家。
- 同城父母不再来电问是否赶回家过年；后事安排费用至少一万元，告别文案改为亲人的自然来电。日常开支标清个人或两人合计及每人每月金额。
- 养老金逐年记录缴费与账户，公职年份另外累计职业年金；退休选择与顶部直接展示每月金额，退休后迁居不重新算低养老金。算法和简化说明集中在 [ECONOMY.md](ECONOMY.md)。
- 半工半读支持升学、考研与考博：期间收入减少 30%，次年查录取，通过后完成三年课程才提升一级学历；学历改善岗位、工资及晋升机会，仍受其他因素影响。
- 恋爱至少两年后再谈婚姻，婚后至少两年讨论生育；分手、低概率离婚和生育困难避免同年叠加。聊天由人物直接表达。
- 新增大平层、别墅；存款可转入定期储蓄、稳健组合或股票基金，估值、取回与净资产分别核算。每年约 2% 出现一项虚构社会背景，涉及产业政策、传染病、国际冲突、股市和行业规则，可影响收入、健康或账户。
- 酷儿主支线仍为每段人生 3%；主动社交遇旧相识的 5% 告白是另外的条件概率，合计不宣称严格 3%。

验证：`node scripts/check-v07.cjs` 覆盖上述家庭、债务、知识、升学、招聘与养老流程；DOM 回归检查新事件和收藏更新时保留既有节点。

## 0.6：升学、工作与身边的人

- 高考、查分、院校志愿、专业志愿和录取分开进行；保留 985 / 211 / 一本 / 二本 / 三本 / 专科层次，学校影响招聘工资。报到文案按双亲、单亲、无人送行与关系疏远分支展示。
- 每组给出三份招聘岗位，可逐一面试或换一组；40% 概率出现专业相关岗位。迁居只改变住处；在职可寻找机会，裁员后下一年再求职。考公需辞职备考，下一年公布结果。
- 薪资从地区工资统计锚点生成，年度有涨有跌，低知识与 35 岁后部分企业员工承担更多风险；全职工资保留最低工资下限。裁员说明先通知裁撤岗位，再核算经济补偿和协商补助，处理高薪封顶。
- 同桌和朋友拥有固定姓名、联系与死亡记录；交往由玩家同意，低频主动邀约、旧相识告白、分手与求婚持续发生。父母离世后可安排后事，父母均离世后结算存款遗产；老宅有人住时保留，无人居住再出售。
- “生活安排”提供课程、健身、自己与父母体检、相亲、重新求职和迁居，也保留房车管理。生活重心在主界面；退休后移除“事业”；“家人 · 账本”靠右。控制高度统一，事件不再重复播放入场动画，信纸在展示结果后恢复底部圆角。
- 地方事件按当前城市触发，死亡家人不再来电或陪同散步；降低知识自然增长和选择加成。正文与选项去掉模型说明，来源与限制集中放在数据页及 [ECONOMY.md](ECONOMY.md)。

验证新增：`node scripts/check-v06.cjs`，覆盖升学顺序、薪资、岗位 40% 抽样、35 岁风险、下一年备考与求职、补偿封顶、姓名存档、交往同意、遗产占用与活动结算。

## 0.5：界面收纳与生活节奏

- 顶部提供首页、播放暂停和速度，辅助导航收入“更多”；健康、心情、知识、关系及收支紧接顶部，状态跟随姓名显示。
- “花钱”从小学开始出现，提供读书、技能课、三年继续教育；成年后可买卖房车、出租房产和搬去其他城市重新求职。其它操作收入二级菜单，移除年度行动和记录筛选栏。
- 年内事件随进度逐条出现，暂停、回到首页和恢复存档均保留展示进度。
- 企业薪酬可能上升、下降或遭遇裁员，低知识角色波动更大。裁员按游戏中的 N+1 结算，可能遇到拖欠、协商与追索；赔偿单独计入账本。这些概率与金额是虚构模型。
- 降低自然学习、选择和课程的知识增幅，工作后长期不学习会缓慢遗忘。
- 小学毕业按种子随机呈现同学录或来信，选择和结果各自对应；随存档归档，重读保持原样。信纸与选项无缝衔接，保留原作版式。
- 普通日常不再附带泛泛的“关于这条记录”，有数据来源或具体模型说明时才显示。

验证：`node scripts/check-cn.cjs`、`node scripts/check-v03.cjs`、`node scripts/check-v04.cjs`、`node scripts/check-v05.cjs`。`scripts/check-interface.cjs` 使用外部安装的 LinkeDOM 做 DOM 交互回归，通过 `CN_DOM_MODULE` 指定模块路径。

## 0.3 更新

- 恢复原作 `.pxstage` 舞台与 `.famscene` 家庭动画，直接迁移 `app.js` 中的像素道具、呼吸、跳跃、走路、家人同行、事件动作和出生家庭场景。适配中文字段，不加载原作的日本游戏引擎界面。
- 学龄前隐藏生活重心，六岁后显示；引擎也不对学龄前应用生活重心加成。生活重心、事件筛选使用自定义菜单，支持键盘、触控与焦点反馈。
- 资产管理支持最多 5 套房的全款/首付购买、自住、出租、空置、出售；每年更新估值、租金、维护及还贷。车辆支持买卖、用车费用与折旧。旧房产迁为名下房产，旧借款余额保留。
- 酷儿相关支线按**整局 3%**开关抽样，不逐年累加。其中约 2/3 是主角同性心动，约 1/3 是直人收到同性告白；不是现实人口统计。同性伴侣进入长期承诺而非异性婚育分支。
- 出柜分朋友、家人、工作场合独立选择。自动模式也必须等待玩家决定；向家人朋友公开不会自动传至职场。工作场合公开后，虚构基层单位有晋升歧视情节，可寻求支持、保留岗位或离职转企业。它不是现实政策说明。

## 存档兼容

继续使用 `1incn-v1:` 浏览器存储键，接受 `cn-0.1.0`、`cn-0.2.0` 与 `cn-0.3.0` 的有效 JSON。旧版姓名、年龄、便签、时间线与已做选择保留，新增字段按迁移规则补充；此后推进采用新版本规则，因此升级前后的未来结果不保证相同。

导入文件上限 2 MB。解析和结构检查通过后才替换当前记录，异常文件不覆盖原存档。导入与模拟不上传数据。清除浏览器数据会删除本地记录，重要人生请导出保存。

## 文件关系

- `index.html`、`cn-app.js`、`cn.css`：入口、交互与中国模式布局。
- `cn-engine.js`：生命周期、选择、种子恢复与存档检查。
- `cn-local.js`：中国生活分支、地域素材、住房与收支、年度主动安排。
- `cn-views.js`：账本、同日人生、点滴收集与离线人生册。
- `cn-family.js`：领养审核、红包、孩子升学与孙辈照护。
- `cn-study.js`：半工半读、录取、毕业及学历层次。
- `cn-finance.js`：资金账户、年度估值、取回与现金流。
- `cn-world.js`：低频虚构社会背景。
- `cn-pension.js`：缴费、个人账户、职业年金与退休报价。
- `cn-data.js`：省级人口、全国指标、姓名与模型参数、数据来源。
- `cn-assets.js`：资产交易、贷款归集、房价和租金、车辆费用与折旧。
- `cn-queer.js`：整局低频支线、取向、告白、分范围出柜及虚构职场偏见。
- `cn-animation.js`：从原作直接迁移的舞台与出生家庭动画。
- `cn-visuals.js`：从原作 `app.js` 提取的像素人物，调整了校服配色。
- `data.js`、`engine.js`、`style.css`、`illust.js`、`pxscenes.js`、`audio.js`、`clair.js` 等为保留的上游实现与资源。
- `upstream/` 保存原作首页和 README 快照；其余原作源码供后续迁移参考。公共仓库快照获取日期为 2026-10-23。

## 数据和模型范围

省份以 2020 年七普常住人口加权，**不是当前各省年度出生比例**；代表城市随机选取。全国人口、出生、死亡与人均可支配收入采用 2025 年统计公报。完整出处在 `cn-data.js` 和界面的数据说明中。

城乡、家庭、姓名、录取、职业收入、城市价格档位、婚恋、照护和退休是游戏设定。借款固定参数仅用于模拟，不对应真实报价或政策；寿命仍使用简化模型，尚未按中国生命表校准。地方食物和生活场景是叙事素材，不代表当地每个人的生活。

只含当代模式，未迁移日本时代模式、真实机构名单和联网排行榜。人生簿是本地记录，“同日人生”不是统计研究。
